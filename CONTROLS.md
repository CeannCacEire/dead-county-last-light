# Controls

## Touch

| Control | Position (portrait) | Function |
| --- | --- | --- |
| Floating joystick | Lower left, appears where you press | Move. Independent of the camera and of the aim hand |
| Aim | Drag anywhere on the right half | Rotate to aim. Tap to face a point |
| Act | Large button, lower right | Context action: pick up, open, search, build. Hold for long actions |
| Attack | Lower centre | Attack with the equipped item |
| Search | Right edge | Opens the list of actions for the highlighted object |
| Sprint | Right edge | Run while held (uses stamina) |
| Crouch | Right edge | Toggle crouch (quieter, harder to see) |
| Pack | Left edge | Inventory |
| Map | Left edge | Full map |
| Heal | Left edge | Quick heal with the best available medical item |
| Light | Right edge | Toggle the held flashlight or torch |
| Pause | Top right | Pause and settings |
| Journal | Hidden by default | Can be shown in the button editor |
| Hotbar | Bottom centre | Tap a slot to equip or use the pinned item |

Move and aim work at the same time. Every touch is tracked by its own pointer, so releasing one finger never releases another control. Taps on buttons and panels never reach the world beneath them. Controls release automatically when the tab is hidden, the window loses focus or the device is rotated.

### Zoom

Pinch with two fingers on the right side of the screen, or use the mouse wheel. The camera zooms smoothly and never reveals unloaded areas.

### Layout options (Settings, Controls)

- **Left-handed layout** mirrors the joystick and buttons.
- **Customise controls** lets you drag, resize and hide each button separately for portrait and landscape. Reset layout restores defaults.
- **Button opacity** and **Button labels** change how strongly the buttons show.
- **Tap once for long actions** replaces holding Act with a single tap.
- **Vibration feedback** gives short haptic pulses where the device supports them.

## Keyboard and mouse

| Key | Function |
| --- | --- |
| `W` `A` `S` `D` | Move |
| Mouse | Aim |
| Left click or `Space` | Attack |
| `E` (hold) | Interact, pick up, search |
| `F` | Action list for the highlighted object |
| `Shift` | Sprint |
| `Ctrl` or `C` | Crouch |
| `Tab` | Inventory |
| `1` to `6` | Hotbar |
| `R` | Crafting |
| `B` | Build |
| `M` | Map |
| `J` | Journal |
| `K` | Skills |
| `L` | Flashlight |
| `H` | Quick heal |
| `Esc` | Pause |
| `F3` | Performance overlay |
| Mouse wheel | Zoom |

In the inventory, desktop players can drag an item to another cell. Everyone can tap an item and then tap an empty cell. Press and hold a stack to split it in half.
