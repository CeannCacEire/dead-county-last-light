# Credits and licences

## Graphics

All artwork is original and drawn in code at runtime with the Canvas 2D API: terrain, sprites, props, buildings, icons, lighting, weather and the animated title screen. There are no image files, sprite sheets or fonts in the project. The interface uses the system font stack.

## Audio

All sound is original and synthesised at runtime with the Web Audio API: effects, footsteps, ambience, creature voices and music. There are no audio files in the project.

## Code

All code is original and has no dependencies. See [LICENSE](LICENSE).

## Third-party material

None. No assets, names, maps, characters, interface layouts, sounds or code from any other game are used.
